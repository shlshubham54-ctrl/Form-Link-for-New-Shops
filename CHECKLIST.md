# New shop: what I need from the shopkeeper

The form (`onboarding/index.html`) asks for all of this. When the shopkeeper taps **Send on WhatsApp**,
a formatted message opens addressed to +91 85330 53912, and they press Send.

## Required
- Shop name
- Owner name
- Owner WhatsApp number
- Address & area

## Shop details
- Type of shop (café, restaurant, pizza, sweets, tea, salon, gym, clothing…)
- Food type: Pure Veg / Veg + Non‑veg / not food (decides which food photo I use)
- Tagline / slogan
- Opening hours

## Links (whatever they have)
- Google Maps link
- Google review link (Google Business Profile → **Ask for reviews**)
- Instagram profile (their own shop account, not a blogger's reel)
- Facebook, YouTube, Zomato / Swiggy / website

## Features they want (toggles)
Menu · Google review · Instagram follow · Directions · Rewards card · Wi‑Fi · Anonymous feedback · Mini game · Call / WhatsApp order

These sections only appear if the matching feature is switched on:
- **Menu:** how they'll share it (photos or typed), and their top 3–5 best sellers (used in review suggestions)
- **Rewards:** visits/stamps needed and the free reward
- **Wi‑Fi:** network name and password
- **Orders:** call number and WhatsApp order number

## Look & feel
- Brand colours (or "same as logo")
- Review suggestion language: Hinglish / English / Both

## Table stands
- How many tables/counters need an NFC stand
- Anything else

## Photos (sent in the same WhatsApp chat afterwards)
WhatsApp links can't carry photos, so the form asks them to send these right after the message:
1. **Logo.** The original file (PNG / PDF / CDR from their printer) is best; otherwise a clear, straight photo.
2. **Menu card.** Every page, flat, in good light.
3. **3–5 best product photos.** Real food or products, used as the page background.
4. **Shop front / inside photo** (optional).
